🔄 Информационный процесс

Информационный процесс — совокупность последовательных действий (операций), производимых над информацией для получения результата.

Основные виды:

  • обработка информации
  • хранение информации
  • передача информации
Обработка информации — целенаправленный процесс изменения содержания или формы представления информации.

⚙️ Виды обработки информации

1. Получение нового содержания:

  • преобразование по правилам
  • исследование объектов по их моделям
  • логические рассуждения

2. Изменение формы представления:

  • кодирование
  • структурирование
  • поиск и отбор информации
Схема: Исходная информация → Алгоритм обработки → Результат

🔐 Кодирование и код

Кодирование — обработка информации, заключающаяся в её преобразовании в форму, удобную для хранения, передачи и обработки.

Код — система условных обозначений (кодовых слов) для представления информации.

Кодовая таблица — совокупность используемых кодовых слов и их значений.

📡 Азбука Морзе

Самый известный пример неравномерного кода. Буквы кодируются последовательностями «точек» и «тире», разделённых паузами.

A · —B — · · · C — · — ·D — · · E ·F · · — · G — — ·H · · · · I · ·J · — — — K — · —L · — · · M — —N — · O — — —P · — — ·

Правила: точка = 1 единица, тире = 3 единицы, пауза между знаками = 3 единицы, между словами = 7 единиц.

📌 Пример

Расшифруйте слово по временнóй шкале:

— · · · — · — — · — ·

Решение: B (—···) + Y (—·——) + T (—) + E (·) = BYTE

✖️ Правило умножения

Если элемент A можно выбрать n способами, а элемент B — m способами, то пару (A, B) можно выбрать n · m способами.

📌 Пример

Условие: Кодовый замок имеет три кольца с цифрами от 0 до 9. Сколько различных комбинаций можно на нём закодировать?

Решение: На каждом кольце 10 вариантов. Всего:

10 · 10 · 10 = 1000 комбинаций
📌 Пример

4 цвета для каждого из 3 элементов: 4³ = 64 способа. Для 8 элементов: 4⁸ = 65 536 способов.

🎲 Комбинаторика: сочетания

Сочетание из n по k — набор k элементов, выбранных из n различных элементов (порядок не важен).

C(n, k) = n! / (k! · (n − k)!)

где n! = 1 · 2 · … · n.

📌 Пример

Условие: Алфавит {A, B, C, D}. Сколько существует последовательностей из 7 символов, содержащих ровно 5 букв A?

Решение:

  1. Выбираем 5 позиций для A из 7: C(7,5) = 21 способ.
  2. На оставшихся 2 позициях — любые из 3 букв (B, C, D): 3² = 9 способов.
  3. Итого: 21 · 9 = 189 последовательностей.
C(7,5) · 3² = 21 · 9 = 189

🌳 Префиксный код

Префиксный код — код со словами переменной длины, в котором никакое кодовое слово не является началом другого (более длинного) кодового слова.

Пример префиксного кода: 0, 10, 11.

Пример НЕ префиксного: 0, 10, 100 (10 — начало 100).

Префиксный код всегда допускает однозначное декодирование.
📌 Пример

Условие: Двоичные коды: A→000, B→011, C→001, D→0011... (из таблицы). Декодируйте строку 0110100011000.

Решение: последовательно читаем код:

011 → B
010 → D
0011 → C
000 → A

Ответ: BDCEA

📜 Прямое и обратное условие Фано

Прямое условие Фано: ни одно кодовое слово не является началом другого.

Обратное условие Фано: ни одно кодовое слово не является окончанием другого.

Достаточно выполнения одного из условий для однозначного декодирования.

Роберт Марио Фано — итальяно-американский учёный, известный работами в теории информации.
📌 Пример

Условие: Коды: А→0, Б→10, В→110. Каким может быть код для Г?

Решение: строим дерево. Свободная ветка — 111. Значит, Г → 111.

(root) / \ 0(A) 1 / \ 0(Б) 1 / \ 0(В) 1(Г)

🌲 Кодовые деревья

Дерево — иерархическая структура из вершин и рёбер. Корень — вершина без входящих рёбер. Листья — вершины без исходящих рёбер.

Двоичное (бинарное) дерево — из каждой вершины выходит не более двух рёбер (0 и 1).

(root) / \ 0 1 / \ / \ 0 1 0 1

Комбинации, соответствующие листьям, — это кодовые слова префиксного кода.

🔄 Перевод чисел

Из десятичной в двоичную: делить на 2, записывать остатки в обратном порядке.

23₁₀ = 10111₂

Из двоичной в десятичную: умножать каждую цифру на 2 в степени разряда (справа налево, начиная с 0).

10101₂ = 16+4+1 = 21₁₀
Хитрый способ: 41 = 32 + 8 + 1 = 2⁵ + 2³ + 2⁰ → 101001₂

🔍 Метод последовательного перебора

Применяется для неструктурированного набора данных.

  • Поиск завершается, когда найден элемент или просмотрены все элементы.
  • Длительность поиска: L = N/2 (в среднем), L = N (в худшем случае).
📌 Пример

Условие: В магазине 9 коробок с обувью. Нужно найти пару для одинокой кроссовки.

Решение: последовательно открываем коробки, пока не найдём пару. В среднем — 4–5 проверок, в худшем случае — 9.

⚡ Метод половинного деления

Применяется для упорядоченного набора данных.

  • Сравниваем с центральным элементом [N/2] + 1.
  • Если не совпало — ищем в одной из двух частей.
  • Длительность поиска: N = 2L, то есть L = log₂N.
📌 Пример

Условие: 9 складов, заполнены по порядку. Найти первый незаполненный за меньшее число ходов.

Решение: открываем склад №5. Если заполнен → ищем в 6–9, иначе в 1–4. Каждый раз делим пополам.

📊 Алгоритм Хаффмана

Строит оптимальный префиксный код: более частым символам — более короткие коды.

  1. Создать узлы с частотами.
  2. Извлекать два узла с наименьшими частотами.
  3. Объединять их в новый узел с суммарной частотой.
  4. Повторять, пока не останется один корень.

Путь от корня: левая ветка — 0, правая — 1.
