📌 Что такое система счисления?

Система счисления — это совокупность правил и приёмов записи чисел с помощью определённого набора знаков (цифр).

Количество цифр, используемых в системе, называется её основанием.

Пример: в десятичной системе основание = 10 (цифры 0–9), в двоичной = 2 (цифры 0, 1).

🗂️ Виды систем счисления

1. Унарные — используют только один знак (например, счёт на пальцах, зарубки).

2. Непозиционные — значение цифры не зависит от её места в числе.

  • Пример: римская система (I, V, X, L, C, D, M).
  • В числе XXX значение каждого X одинаково — 10.

3. Позиционные — значение цифры зависит от её позиции (разряда).

  • Пример: десятичная, двоичная, восьмеричная, шестнадцатеричная.

🏛️ Римская система счисления

Непозиционная система. Цифры: I = 1, V = 5, X = 10, L = 50, C = 100, D = 500, M = 1000.

Правила перевода:

  • Если меньшая цифра стоит перед большей — она вычитается (IV = 4, IX = 9).
  • Если меньшая стоит после большей — прибавляется (VI = 6, XI = 11).
  • Одна и та же цифра не может стоять подряд более трёх раз.
📌 Пример

MCMXCVIII = 1000 + (1000 − 100) + (100 − 10) + 5 + 1 + 1 + 1 = 1998.

📝 Развёрнутая запись числа

Любое число в позиционной системе можно записать в виде суммы произведений цифр на степени основания.

A = an·qn + ... + a1·q1 + a0·q0 + a-1·q-1 + ...

где q — основание, a — цифры.

📌 Пример (целое)

253₁₀ = 2·10² + 5·10¹ + 3·10⁰ = 200 + 50 + 3.

📌 Пример (дробное)

101,11₂ = 1·2² + 0·2¹ + 1·2⁰ + 1·2⁻¹ + 1·2⁻² = 4 + 0 + 1 + 0,5 + 0,25 = 5,75₁₀.

➡️ Перевод в десятичную систему

Используем формулу развёрнутой записи: умножаем каждую цифру на основание в степени её позиции и складываем.

📌 Пример

1101₂ = 1·2³ + 1·2² + 0·2¹ + 1·2⁰ = 8 + 4 + 0 + 1 = 13₁₀.

2A₁₆ = 2·16¹ + 10·16⁰ = 32 + 10 = 42₁₀.

⬅️ Перевод из десятичной системы

Для целых чисел: делим на основание, записываем остатки в обратном порядке.

📌 Пример

45₁₀ в двоичную:

45 ÷ 2 = 22 (ост. 1)
22 ÷ 2 = 11 (ост. 0)
11 ÷ 2 = 5 (ост. 1)
5 ÷ 2 = 2 (ост. 1)
2 ÷ 2 = 1 (ост. 0)
1 ÷ 2 = 0 (ост. 1)

Читаем остатки снизу вверх: 101101₂.

🔢 Перевод дробных чисел

Из десятичной в другую: умножаем дробную часть на основание, выделяем целую часть, повторяем с остатком.

📌 Пример

0,625₁₀ в двоичную:

0,625 · 2 = 1,25 → целая 1
0,25 · 2 = 0,5 → целая 0
0,5 · 2 = 1,0 → целая 1

Читаем сверху вниз: 0,101₂.

📊 Таблицы триад и тетрад

Для быстрого перевода между двоичной, восьмеричной и шестнадцатеричной системами используют таблицы.

Триады (2 ↔ 8): каждые 3 двоичных разряда = 1 восьмеричная цифра.

2 сс000001010011100101110111
8 сс01234567

Тетрады (2 ↔ 16): каждые 4 двоичных разряда = 1 шестнадцатеричная цифра.

2 сс00000001001000110100010101100111
16 сс01234567
2 сс10001001101010111100110111101111
16 сс89ABCDEF
Совет: при переводе из 2 в 8 разбивайте число на триады справа налево, из 2 в 16 — на тетрады.
